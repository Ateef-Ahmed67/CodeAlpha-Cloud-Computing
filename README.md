
# CodeAlpha Cloud Computing Internship

This repository contains the projects completed as part of my CodeAlpha Cloud Computing Internship.

## Projects

### Task 1 - Data Redundancy Removal System

A cloud-based system that identifies and prevents duplicate records from being stored in a cloud database.

**AWS Services:**
- AWS Lambda
- Amazon DynamoDB
- Amazon API Gateway

**Key Features:**
- Duplicate detection
- SHA-256 based record identification
- Conditional database insertion
- REST API
- Cloud database storage

### Task 2 - Cloud-Based Bus Pass System

A cloud-based bus pass booking system designed to provide online booking, automatic pricing, duplicate booking prevention, and reliable cloud storage.

**AWS Services:**
- AWS Lambda
- Amazon DynamoDB
- Amazon API Gateway

**Key Features:**
- Online bus pass booking
- Automatic price calculation
- Duplicate booking prevention
- Unique booking identification
- Booking status tracking
- GET API for retrieving bookings
- Serverless architecture

## Architecture

### Task 1

Client → API Gateway → AWS Lambda → DynamoDB

### Task 2

Client → API Gateway → AWS Lambda → DynamoDB
